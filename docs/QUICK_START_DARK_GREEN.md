# TaskFlow Dark & Green Theme - Quick Start Guide

## 🎨 Theme Toggle (Top-Right Corner)
- **Sun/Moon Icon**: Toggle between Dark & Light modes
- **Blue Button**: Switch to Dark/Blue theme
- **Green Button**: Switch to Dark/Green theme

Selected theme saves automatically! 

## 🎯 New Jira-Like Features

### What You Can Now Do:

1. **Assign Team Members**
   - Edit task → Type name in "Assignee" field
   - Appears as avatar with first letter

2. **Add Priority Levels**
   - Low, Normal, High, or Critical
   - Color-coded badges: Gray → Blue → Orange → Red

3. **Assign Story Points**
   - Estimate task complexity (1-13 recommended)
   - Tracks total project effort
   - Shows % progress based on completed points

4. **Add Labels/Tags**
   - Type label name → Press Enter or click "Add"
   - Display up to 2 tags per card
   - Purple colored badges

5. **View Progress Dashboard**
   - **Progress %**: Completed points / Total points
   - **Total Points**: Sum of all story points

## 🎨 Dark Theme Colors

### Default (Dark/Blue)
- Background: Deep navy
- Cards: Slate
- Accents: Blue
- Buttons: Blue

### Green Variant
- Background: Deep navy (same)
- Cards: Slate (same)
- Accents: Vibrant green
- Buttons: Green
- Perfect for high-contrast viewing

## 📝 Task Card Display

Each task now shows:
```
#1 [Task Title]
[Description preview...]
------
[Points] [Priority Badge] [Label1] [Label2] [+1] [@Avatar]
```

## 🚀 Tips

1. **Use AI Suggest** - Click button to auto-estimate points & priority
2. **Multi-label** - Add multiple tags for better categorization
3. **Keyboard Input** - Press Enter in label field to add
4. **Theme Persistence** - Your choice saves between sessions
5. **High Contrast** - Green theme is easier on eyes in low light

## 🔄 Workflow Example

1. Create task: "Implement authentication"
2. Click to edit
3. Set Priority: **High**
4. Set Points: **8**
5. Assign to: **John**
6. Add labels: **Backend**, **Security**
7. Drag to "In Progress"
8. Dashboard updates automatically!

## 💡 Best Practices

- Use points consistently (1=tiny, 3=small, 5=medium, 8=large, 13=epic)
- Assign critical tasks first
- Use labels for project/component tracking
- Review progress % to track sprint completion
- Toggle green theme if blue causes eye strain

Enjoy your enhanced TaskFlow! 🎉
